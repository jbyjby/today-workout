# 오늘운동

휴대폰과 PC 브라우저에서 쓰는 개인 운동 기록 PWA입니다. 기록은 서버로 보내지 않고 현재 브라우저의 `localStorage`에 저장됩니다.

## 실행

이 폴더에서 다음 명령을 실행합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 휴대폰에 설치

같은 네트워크에서 HTTPS로 서비스하거나 정적 호스팅에 올린 뒤, 브라우저 메뉴의 `홈 화면에 추가`를 선택합니다. 앱 하단의 `설치` 버튼도 지원되는 브라우저에서는 설치 창을 엽니다.

## 주요 기능

- 기본 루틴 3종과 사용자 루틴 추가·삭제
- 운동별 중량·반복·세트 완료 기록
- 운동 시간과 90초 휴식 타이머
- 최근 7일 빈도·볼륨, 연속 운동일, 누적 통계
- 라이트·다크 테마
- JSON 백업 내보내기·가져오기
- 오프라인 캐시와 홈 화면 설치(PWA)

## 데이터 주의

브라우저 데이터나 사이트 저장 공간을 삭제하면 기록도 삭제됩니다. `기록` 화면의 내려받기 버튼으로 정기 백업하세요.
